## 6. 统一验收清单

- [ ] `pages_modules/llm.py` 导出 `show()` 函数可被 `main.py` 路由调用。
- [ ] 支持 DeepSeek、智谱GLM、通义千问、文心一言四款模型的无缝切换。
- [ ] 每个模型使用独立的 session_state 键（`llm_messages_*`）管理对话历史。
- [ ] API Key 通过 `st.secrets` 获取，支持 `config.get_api_key()`。
- [ ] 所有模型均实现流式（SSE）对话输出。
- [ ] 请求失败时实现指数退避重试（最多 3 次）。
- [ ] 已配置的 API Key 在界面上以安全方式指示可用状态。
- [ ] 模型介绍卡片突出各模型差异化优势而非泛泛的描述。
- [ ] 推荐提问示例覆盖代码、数学、写作、知识问答、推理五个维度。
- [ ] Temperature / Max Tokens 参数有完整的中文解释与使用建议。
- [ ] 错误提示包含解决方案指引，非技术用户可独立完成配置。
- [ ] `config.json` 是合法 JSON。
- [ ] 无 PyTorch/TensorFlow 依赖。
- [ ] 所有 Streamlit 状态键统一使用 `llm_` 前缀。
