# AI 算法可视化学习平台 · 机器学习模块统一预期输出示例

## 1. 总体交付结构

```text

 _internal/
 ├── main.py
 └── pages_modules/
     ├── classification_lab.py
     ├── regression_lab.py
     └── clustering_lab.py

 ├──prompt_engineering/
    └── 机器学习/
    ├── prompt_template.txt
    ├── example_output.md
    └── config.json
```

说明：
- `main.py` 负责把“分类”“回归”“聚类”三个机器学习页面路由到对应页面模块。
- `classification_lab.py`、`regression_lab.py`、`clustering_lab.py` 分别负责正式可视化学习页面与顶部趣味引入小游戏。
- `prompt_template.txt`、`example_output.md`、`config.json` 构成机器学习模块提示词标准化三件套。

## 2. 分类模块

### 2.1 布局示意

```text
页面顶部
├── 基础知识展开区
├── AI 分类小测验
├── 引导语：进入正式可视化学习
└── 正式学习区域
    ├── 左侧：算法选择、数据集选择、参数调节
    ├── 中间：决策边界与样本分布主图
    ├── 下方：准确率、混淆矩阵、错分样本与图像解读
    └── 教学提示：参数解释、结果结论、类别含义说明
```

### 2.2 页面顶部小游戏

- 标题：`AI 分类小测验`
- 作用：通过垃圾邮件、水果类型、学习状态等生活化示例，帮助学生先理解“分类任务是在多个类别中做判断”。
- 交互要求：
  - 单选题或下拉选项；
  - `提交答案` 按钮；
  - `再来一题` 按钮；
  - 提交后显示反馈和概念引导语。

### 2.3 页面行为预期

| 区域 | 预期内容 | 预期行为 |
| --- | --- | --- |
| 顶部小游戏 | AI 分类小测验 | 可切题、可提交、可显示正确答案与解释 |
| 操作区 | KNN、SVM、朴素贝叶斯、随机森林 | 切换算法后数据集与参数控件同步变化 |
| 数据区 | 算法专属数据集 | 切换数据集后主图与指标同步刷新 |
| 主图区 | 决策边界与训练/测试样本 | 参数变化后边界形状实时变化 |
| 指标区 | 训练准确率、测试准确率、泛化差距、错分样本、混淆矩阵 | 能用于对比模型效果与泛化能力 |
| 教学区 | 图像解读、参数说明、类别含义说明 | 中文说明清晰，不遮挡主图 |

## 3. 回归模块

### 3.1 布局示意

```text
页面顶部
├── 基础知识展开区
├── AI 数值预测小游戏
├── 引导语：进入正式可视化学习
└── 正式学习区域
    ├── 左侧：算法选择、数据集选择、参数调节
    ├── 中间：拟合曲线与样本分布主图
    ├── 下方：诊断图、R²、MSE、MAE、RMSE
    └── 教学提示：拟合解释、欠拟合/过拟合说明、参数建议
```

### 3.2 页面顶部小游戏

- 标题：`AI 数值预测小游戏`
- 作用：通过成绩预测、房价指数预测、体能评分预测等情境，让学生先理解“回归任务是预测连续数值”。
- 交互要求：
  - `number_input` 输入预测值；
  - `提交预测` 按钮；
  - `再来一题` 按钮；
  - 提交后显示参考答案、误差和反馈。

### 3.3 页面行为预期

| 区域 | 预期内容 | 预期行为 |
| --- | --- | --- |
| 顶部小游戏 | AI 数值预测小游戏 | 可输入数值、提交、显示误差、切换下一题 |
| 操作区 | 线性回归、多项式回归、岭回归、Lasso、SVR、决策树回归、随机森林回归 | 切换算法后参数控件与默认数据集同步变化 |
| 数据区 | 线性趋势、曲线趋势、相关特征、噪声扰动等数据集 | 切换数据集后主图和指标同步更新 |
| 主图区 | 拟合曲线与样本分布 | 参数变化后曲线形态与点云解释同步变化 |
| 结果图区 | 结果诊断图、真实值与预测值对照、残差 | 可帮助识别欠拟合、过拟合或异常偏差 |
| 指标区 | train_r2、test_r2、MSE、MAE、RMSE | 用于评价拟合效果与泛化能力 |

## 4. 聚类模块

### 4.1 布局示意

```text
页面顶部
├── 基础知识展开区
├── AI 分组小游戏
├── 引导语：进入正式可视化学习
└── 正式学习区域
    ├── 左侧：算法选择、数据集选择、参数调节
    ├── 中间：聚类结构主图
    ├── 下方：结构分析图、簇数量、噪声点统计、评价指标
    └── 教学提示：结构解读、调参与结果提示
```

### 4.2 页面顶部小游戏

- 标题：`AI 分组小游戏`
- 作用：通过学生兴趣分组、用户行为分群、城市区域特征分组等例子，让学生理解“聚类是在没有标准标签时根据相似性发现群体结构”。
- 交互要求：
  - 单选或下拉选择分组数量；
  - `提交答案` 按钮；
  - `再来一题` 按钮；
  - 提交后显示参考分组与解释。

### 4.3 页面行为预期

| 区域 | 预期内容 | 预期行为 |
| --- | --- | --- |
| 顶部小游戏 | AI 分组小游戏 | 可提交、可切题、可显示概念反馈 |
| 操作区 | KMeans、DBSCAN、层次聚类、GMM | 切换算法后参数区与数据集区同步调整 |
| 数据区 | 球状簇、月牙、同心圆、椭圆分布、密度变化等数据集 | 切换数据集后结构图和指标实时更新 |
| 主图区 | 聚类结构图 | 应显示不同颜色簇、中心、噪声点或概率结构 |
| 分析区 | 结构分析图、中心移动、密度连接、层级关系或 GMM 解释 | 内容与当前算法相匹配 |
| 指标区 | 轮廓系数、戴维斯-鲍丁指数、卡林斯基-哈拉巴斯指数、簇数量、噪声点数量 | 指标应随参数变化联动 |

## 6. 统一输出说明

本文件用于说明机器学习模块在提示词标准化体系下的“预期结果长什么样”。实际开发时：

1. `prompt_template.txt` 负责约束角色、任务与格式；
2. `example_output.md` 负责约束页面结构、行为预期与验收标准；
3. `config.json` 负责提供模块化、可解析的配置与参数描述。

三者配合后，能够把“机器学习模块要做成什么样”从自然语言描述提升为可重复复用的标准化资源。
