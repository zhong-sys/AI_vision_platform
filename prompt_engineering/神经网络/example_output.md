## 2. 神经网络模块

**布局示意：**

```
┌───────────────────────────────────────────────────────────────┐
│  神经网络可视化训练                                           │
├──────────────────┬────────────────────────────────────────────┤
│ 参数             │  标签页：训练曲线 / 网络结构 / 训练日志      │
│ · 输入层         │                                            │
│ · 隐藏层数量     │  [Loss 与 Accuracy 曲线]                    │
│ · 激活函数       │                                            │
│ · 损失函数       │  [网络拓扑图：权重/激活/梯度模式]            │
│ · 学习率         │                                            │
│ · 构建/重置/训练 │  日志：Epoch、Loss、Accuracy                │
└──────────────────┴────────────────────────────────────────────┘
```

**行为预期：**

| 操作 | 预期结果 |
|------|----------|
| 点击「构建网络」 | 初始化 Trainer，网络结构图可见 |
| 点击「单步执行」 | epoch 增加 1，loss/acc 追加记录 |
| 点击「自动训练」 | 训练到最大轮数，曲线整体刷新 |
| 点击「重置」 | 训练器、曲线、日志、网络构建状态全部清空 |

**验收清单：**

- [ ] `render_neural_network_viz()` 可被 `main.py` 路由调用。
- [ ] `SimpleNN` 使用 NumPy 实现前向传播、反向传播和参数更新。
- [ ] 支持 ReLU、Sigmoid、Tanh、Linear 四种激活函数。
- [ ] 支持交叉熵、MSE、MAE 三种损失函数。
- [ ] 单步训练与自动训练都会更新 `nv_history`。
- [ ] session_state 键均以 `nv_` 为前缀。

```

```

**行为预期：**

| 区域 | 预期结果 |

| 多头注意力 | 多个头并行后拼接输出 |
| Encoder 单层 | 残差连接绕过子层后进入 Add&Norm |
| 模型对比 | CNN、RNN、Transformer 信息流差异同屏可见 |

**验收清单：**

- [ ] `nv_render_transformer_viz()` 可被 `main.py` 路由调用。

- [ ] 本模块没有训练循环与 session_state 副作用。
- [ ] 无 PyTorch/TensorFlow 依赖。
